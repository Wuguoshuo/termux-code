# Skill 11: 结构分析

> **核心目标**: 分析小说结构，规划短剧的集数结构，确定每集的核心事件

---

## 触发时机

完成 Skill 10（小说分析）后，用户确认分析报告后触发。

---

## 工作流程

### Step 1: 确定短剧基本信息

**需要确定**：
- **目标集数**：10-15集（短剧标准集数）
- **单集时长**：3-5分钟
- **总时长**：30-75分钟
- **节奏类型**：快节奏/中节奏/慢节奏

**Think Aloud 示例**:
```
我需要确定短剧的基本信息...

思考：
- 小说有10章，每章5000字，共5万字
- 短剧一般10-15集，每集3-5分钟
- 考虑到：
  1. 喜剧类型，节奏可以稍快
  2. 人物成长线需要足够集数展示
  3. 10集对应小说10章，结构清晰

我的建议：
- 目标集数：10集
- 单集时长：4-5分钟（比标准稍长，保证完整性）
- 节奏类型：中快节奏（喜剧+成长，需要节奏感）

等待用户确认...
```

### Step 2: 分析小说情节结构

**分析小说的**：
- **起承转合**：小说的整体结构
- **章节功能**：每章在整体中的作用
- **关键节点**：必须保留的重要情节点
- **过渡性内容**：可以压缩或删减的内容

**输出格式**:
```markdown
## 二、小说情节结构分析

### 起承转合
- **起**（第1-2章）：进厂、学艺，建立师徒关系
- **承**（第3-5章）：掌握技艺，开始面临抉择
- **转**（第6-8章）：茶厂改制，外出闯荡，转折点
- **合**（第9-10章）：归来，接班，传承技艺

### 章节功能分析
| 章节 | 功能 | 作用 | 保留优先级 |
|------|------|------|------------|
| 第1章 | 开场/设定 | 进场、遇师父、炒糊茶叶 | ⭐⭐⭐⭐⭐ 必须保留 |
| 第2章 | 人物塑造 | 学艺笨拙，师徒关系建立 | ⭐⭐⭐⭐⭐ 必须保留 |
| 第3章 | 技能学习 | 渥堆发酵，技艺提升 | ⭐⭐⭐⭐ 重要 |
| 第4章 | 人物成长 | 陈化管理，学会等待 | ⭐⭐⭐⭐ 重要 |
| 第5章 | 冲突引入 | 周经理提出现代化设备 | ⭐⭐⭐⭐ 重要 |
| 第6章 | 冲突升级 | 茶厂改制风波 | ⭐⭐⭐⭐⭐ 必须保留 |
| 第7章 | 转折点 | 阿三外出闯荡 | ⭐⭐⭐⭐⭐ 必须保留 |
| 第8章 | 外部世界 | 见识市场乱象，眼界大开 | ⭐⭐⭐⭐ 重要 |
| 第9章 | 归来 | 决定回到茶厂 | ⭐⭐⭐⭐⭐ 必须保留 |
| 第10章 | 结局 | 师父退休，阿三接班 | ⭐⭐⭐⭐⭐ 必须保留 |

### 关键节点
1. **进厂遇师父**（第1章）：开场，建立核心关系
2. **炒糊茶叶**（第1章）：首次冲突，喜剧开场
3. **刘师傅给洗洁精**（第1章）：刻画师父刀子嘴豆腐心
4. **掌握技艺**（第2-4章）：主角成长
5. **茶厂改制风波**（第6章）：外部冲突高潮
6. **外出闯荡**（第7-8章）：转折点，眼界开阔
7. **归来接班**（第9-10章）：传承技艺，结局
```

### Step 3: 规划集数结构

**设计原则**：
1. **集数对应章节**：每集对应小说1章（结构清晰）
2. **每集有核心事件**：每集必须有1-2个重要事件
3. **节奏张弛有度**：快节奏集数和慢节奏集数交替
4. **每集有冲突**：外部冲突或内部冲突
5. **每集有悬念**：结尾埋下悬念，吸引观众

**集数结构模板**:
```markdown
## 三、集数结构规划

### 第1集：命运的安排
- **对应章节**：第1章
- **时长**：4-5分钟
- **节奏**：中快节奏（开场需要吸引人）
- **核心事件**：
  1. 陈阿三进茶厂报到
  2. 分到严厉的刘师傅
  3. 首次炒茶，炒糊了
  4. 刘师傅给洗洁精（刀子嘴豆腐心）
- **主要冲突**：师徒冲突（阿三笨拙 vs 刘师傅严厉）
- **悬念**：刘师傅和阿三的父亲是师兄弟，为什么不提？
- **开场**（0-30秒）：阿三进厂，环境介绍，快速
- **发展**（30秒-2分钟）：报到、分师父、炒糊茶叶
- **高潮**（2-4分钟）：炒糊茶叶，被骂
- **收尾**（4-5分钟）：刘师傅给洗洁精，悬念

### 第2集：学艺的日子
- **对应章节**：第2章
- **时长**：4-5分钟
- **节奏**：中节奏（成长线，可以稍慢）
- **核心事件**：
  1. 学习杀青、揉捻
  2. 经常犯错，被笑话
  3. 师徒关系建立（刘师傅虽然骂，但教得认真）
- **主要冲突**：学艺困难 vs 师父严厉
- **悬念**：阿三能否学会？
- **开场**（0-30秒）：学艺失败的搞笑场面
- **发展**（30秒-3分钟）：学习过程，错误百出
- **高潮**（3-4分钟）：阿三终于学会一点，师父点头
- **收尾**（4-5分钟）：师徒关系稍微改善

### 第3集：渥堆初体验
- **对应章节**：第3章
- **时长**：4-5分钟
- **节奏**：中节奏（核心技艺学习）
- **核心事件**：
  1. 学习渥堆发酵（六堡茶核心工艺）
  2. 师父教得很严
  3. 阿三压力很大，但学会了
- **主要冲突**：技艺难度 vs 阿三能力
- **悬念**：阿三能否掌握核心技艺？
- **开场**（0-30秒）：师父讲解渥堆的重要性
- **发展**（30秒-3分钟）：渥堆过程，阿三紧张
- **高潮**（3-4分钟）：翻堆时的搞笑场面
- **收尾**（4-5分钟）：阿三学会，师父认可

...（第4-10集，同上结构）

### 集数节奏规划
| 集数 | 节奏 | 理由 |
|------|------|------|
| 第1集 | 中快 | 开场，吸引观众 |
| 第2集 | 中 | 成长线，可以稍慢 |
| 第3集 | 中 | 核心技艺学习 |
| 第4集 | 中 | 成长线 |
| 第5集 | 中快 | 冲突引入 |
| 第6集 | 快 | 冲突升级 |
| 第7集 | 快 | 转折点 |
| 第8集 | 中 | 外部世界，节奏稍慢 |
| 第9集 | 中快 | 归来 |
| 第10集 | 中 | 结局，温馨收尾 |
```

- **1集对应1章**（结构清晰）

| 第2集 | 学艺的日子 | 第2章 | 学习杀青、揉捻，经常犯错 | 陈阿三、刘师傅、王胖子 | 4-5分钟 |

### Step 5: 确定可删减内容

**分析小说中可以删减的内容**：
- **过渡性对话**：不影响主线的对话
- **次要场景**：可以用旁白快速交代
- **次要人物**：对主线无关的小角色
- **重复情节**：类似的意思只保留一次

**输出格式**:
```markdown
## 五、可删减内容

### 可删减的对话
1. **日常闲聊**：工人之间的闲聊（可以简化）
2. **过渡性对话**：场景切换时的对话（用旁白）
3. **重复性对话**：类似意思的对话（只保留一次）

### 可删减的场景
1. **吃饭场景**：食堂吃饭（可以用旁白快速交代）
2. **睡觉场景**：宿舍休息（可以删减）
3. **走路场景**：去车间的路上（可以删减）

### 可删减的人物
1. **其他学徒**：除了王胖子，其他学徒可以合并为"群众学徒"
2. **路人角色**：茶厂门口的路人可以删减
3. **次要配角**：对主线无关的小角色

### 可用旁白交代的内容
1. **时间跨度**：几年过去了（用旁白"三年后..."）
2. **茶厂变化**：茶厂设备更新了（用旁白）
3. **社会背景**：90年代国企改制（用旁白）
4. **次要情节**：阿三每天学艺（用旁白）

### 可压缩的情节
1. **学艺过程**：每天学艺可以压缩为几个关键场景
2. **外出闯荡**：广州的经历可以压缩为几个典型场景
3. **茶厂改制**：改制过程可以压缩为几个关键事件
```

## 五、可删减内容

### 可删减的对话
1. **日常闲聊**：工人之间的闲聊（可以简化）
2. **过渡性对话**：场景切换时的对话（用旁白）
3. **重复性对话**：类似意思的对话（只保留一次）

### 可删减的场景
1. **吃饭场景**：食堂吃饭（可以用旁白快速交代）
2. **睡觉场景**：宿舍休息（可以删减）
3. **走路场景**：去车间的路上（可以删减）

### 可删减的人物
1. **其他学徒**：除了王胖子，其他学徒可以合并为"群众学徒"
2. **路人角色**：茶厂门口的路人可以删减
3. **次要配角**：对主线无关的小角色

### 可用旁白交代的内容
1. **时间跨度**：几年过去了（用旁白"三年后..."）
2. **茶厂变化**：茶厂设备更新了（用旁白）
3. **社会背景**：90年代国企改制（用旁白）
4. **次要情节**：阿三每天学艺（用旁白）

### 可压缩的情节
1. **学艺过程**：每天学艺可以压缩为几个关键场景
2. **外出闯荡**：广州的经历可以压缩为几个典型场景
3. **茶厂改制**：改制过程可以压缩为几个关键事件

## 六、改编重点

### 每集必须有核心事件
- 1-2个重要事件，推动情节发展
- 核心事件必须在对应章节中

### 每集必须有冲突
- 外部冲突：主角和反派、主角和环境的冲突
- 内部冲突：主角内心的挣扎

### 每集必须有悬念
- 结尾埋下悬念，吸引观众看下一集
- 悬念可以是人物关系、情节转折、未解之谜

### 每集节奏要张弛有度
- 快节奏集数：冲突密集、对白密集
- 中节奏集数：成长线、情感线
- 慢节奏集数：结局、温馨场面

## 常见错误避免

❌ **不要这样做**:
- 集数太多（超过15集，短剧不适合）
- 每集核心事件不明确
- 没有冲突，只是流水账
- 没有悬念，观众不期待
- 节奏单一（全部快或全部慢）

✅ **应该这样做**:
- 10-15集，单集3-5分钟
- 每集1-2个核心事件
- 每集有冲突（外部/内部）
- 每集结尾有悬念
- 节奏张弛有度（快慢交替）

# Skill 14: 剧本创作

> **核心目标**: 根据场景大纲，创作完整剧本

---

## 触发时机

完成 Skill 13（场景大纲）后，用户确认场景大纲后触发。

## 工作流程

### Step 1: 读取场景大纲

**读取文件**：
- `_scripts/adaptations/第{集数}集-场景大纲.md`

**提取信息**：

```

```

```

```

```
- 中景：陈阿三背着铺盖卷，站在门口
- 特写：陈阿三的脸，表情复杂
```

#### 对白
```
**对白**：
（无）
```

```
**动作**：

他叹了口气，背了背铺盖卷，迈步走进茶厂。
```

```

- 不需要对白，用画面说话
- 时长：15秒
```

### Step 4: 剧本创作要点

#### 1. 对白要求
- **简洁**：不说长句，15秒-1分钟
- **口语化**：不说书面语
- **90年代感**：不说网络用语
- **符合人物性格**：刘师傅嘴毒、阿三憨厚

#### 2. 动作要求
- **具体**：描述具体动作，不模糊
- **推动情节**：动作要推动情节发展
- **外化心理**：心理描写转化为动作

#### 3. 场景描述要求
- **具体**：描述具体的环境、光线、氛围
- **简练**：不冗长，15-30字
- **有画面感**：让读者能想象出画面

#### 4. 镜头指示要求
- **清晰**：景别（全景/中景/特写）
- **合理**：镜头转换合理
- **不冗余**：不是每句对白都需要镜头指示

#### 5. 备注要求
- **道具**：需要准备的道具（铁铲、洗洁精等）
- **音乐**：背景音乐（紧张、温馨等）
- **特效**：特殊效果（炒茶的噼啪声等）
- **备注**：拍摄注意事项

### Step 5: 生成完整剧本

**文件结构**：
```markdown
# 第1集：命运的安排

## 人物表
- 陈阿三：18岁，茶厂学徒
- 刘师傅：50多岁，制茶师傅
- 王胖子：18岁，学徒
- 眼镜叔：40多岁，厂里办事员

## 场景列表
- S1-01 茶厂门口 - 日
- S1-02 办公楼一楼 - 日
- S1-03 制茶车间 - 日
- S1-04 制茶车间 - 日
- S1-05 茶厂门口 - 黄昏

---

S1-01 茶厂门口 - 日

**人物**：陈阿三

**场景描述**：
1992年的夏天，横县茶厂门口。阳光明媚，几栋红砖厂房排在山坡上，旁边是成片的茶园，绿油油的一片。空气里飘着淡淡的茶香。

**镜头**：
- 全景：茶厂大门，红砖厂房，茶园
- 中景：陈阿三背着铺盖卷，站在门口
- 特写：陈阿三的脸，表情复杂

**动作**：
陈阿三站在茶厂门口，抬头看着"横县茶厂"的牌匾。他叹了口气，背了背铺盖卷，迈步走进茶厂。

**备注**：
- 开场需要快速介绍茶厂环境
- 不需要对白，用画面说话
- 时长：15秒

---

S1-02 办公楼一楼 - 日

**人物**：陈阿三、王胖子、眼镜叔

**场景描述**：
办公楼一楼，排了十几个人，大多是和阿三差不多大的年轻人。墙上的挂历显示：1992年7月。

**镜头**：
- 全景：排队的人群
- 中景：陈阿三站在队伍中，王胖子站在旁边

**对白**：
王胖子：（拍拍阿三的肩膀）哎，兄弟，你也是来报到的？

陈阿三：（转头，看到一张圆滚滚的脸）是啊，我叫陈阿三。

王胖子：（笑）我叫王大勇，你叫我胖子就行。我也是刚高中毕业，不想种地，我妈让我进厂当学徒。

陈阿三：（笑）我和你一样，也不想种地。

王胖子：（拍拍阿三的肩膀）那咱俩有缘了，以后多照应啊。

（眼镜叔拿着一张纸走过来）

眼镜叔：你们几个，分师父了。陈阿三，刘建国。王大勇，张建国。其他人，李桂兰……

陈阿三：（犹豫）眼镜叔，等等。

眼镜叔：怎么了？

陈阿三：刚才说我分给谁？

眼镜叔：刘建国，人称刘师傅。

陈阿三：（小声）能……能不能换个师父？

王胖子：（小声）阿三，咋了？刘师傅不好？

陈阿三：（摇头）我昨天听王叔说，刘师傅脾气有点……

王胖子：（嘿嘿笑）有点啥？脾气不好？

陈阿三：（刚要点头）

眼镜叔：不行，分定了。陈阿三，你跟我来。

陈阿三：（叹气，跟着眼镜叔往车间里面走）

王胖子：（喊）兄弟，有事找我啊！我分到张师傅，人可好了！

陈阿三：（头也不回，往前走）

**备注**：
- 展示报到和分师父的过程
- 阿三想换师父，埋下悬念
- 王胖子的性格油滑、嘴甜
- 时长：30秒

---

S1-03 制茶车间 - 日

**人物**：陈阿三、刘师傅、王胖子（背景）、其他工人（背景）

**场景描述**：
茶厂车间比外面热，十几台炒茶机轰隆隆地转着，工人们穿着短袖，额头上冒着汗。空气里全是炒茶的香味。

**镜头**：
- 全景：车间全景，炒茶机轰隆隆
- 中景：刘师傅蹲在一台炒茶机旁
- 特写：陈阿三站在旁边，一脸茫然

**对白**：
刘师傅：（冷冷地）会炒茶吗？

陈阿三：（摇头）

刘师傅：会揉捻吗？

陈阿三：（摇头）

刘师傅：那会干什么？

陈阿三：（思考片刻，脱口而出）会欠钱。

（王胖子和其他工人笑）

刘师傅：（皱眉，盯着阿三）欠钱？

陈阿三：我爸欠了厂里五千块钱，我进厂是为了还债。

刘师傅：（愣了一下，盯着阿三）你爹叫什么？

陈阿三：陈建国。

刘师傅：（眼神闪烁，但很快又暗了下来）陈建国……你爹，是我师兄。

**备注**：
- 债务反转点，首次揭示人物关系
- 对白要快速、紧凑，符合短剧节奏
- "会欠钱"是全剧首句金句，重点处理
- 时长：1分钟

---

S1-04 制茶车间 - 日

**人物**：陈阿三、刘师傅

**场景描述**：
刘师傅走到一台炒茶机旁边，指着铁锅。铁锅已经烧得通红。

**镜头**：
- 中景：刘师傅指着铁锅
- 特写：铁锅，通红
- 特写：陈阿三的脸，紧张

**对白**：
刘师傅：温度烧到180度，茶叶放进去，不停翻动，听见噼啪响就赶紧翻，翻不够茶叶会糊，翻多了茶叶会碎，糊了不行，碎了也不行，你自己看着办。

陈阿三：（点头）明白了。

刘师傅：明白了？你来，炒一锅试试。

陈阿三：（愣了一下，看着铁锅）

刘师傅：来啊，等什么呢？

陈阿三：（硬着头皮走过去，伸出手，却不知道从哪里下手）

刘师傅：你脑子是不是让你爹的遗传给影响了？拿铲子啊！

陈阿三：（赶紧拿起旁边的铁铲）

刘师傅：（指了指一个框子）茶叶在那里。

陈阿三：（用铲子铲了一铲茶叶，犹豫了一下，慢慢放进铁锅里）

刘师傅：（大声）太慢了！茶叶要一下放进去，你这样放，前面的都糊了，后面的还没熟！

陈阿三：（赶紧加快速度，哗啦一下把茶叶全倒了进去）

刘师傅：翻！翻啊！

陈阿三：（拿着铁铲，手忙脚乱地翻着茶叶，铁铲磕在铁锅上，发出"哐哐"的响声）

刘师傅：轻点！你是杀茶还是打铁？

（刘师傅走过来，一把抢过铁铲）

刘师傅：看着！

（刘师傅的手腕灵活地转动，铁铲在铁锅里翻飞，茶叶在锅底跳动，发出噼啪噼啪的响声。他的动作很快，但不慌不忙，每一下都恰到好处。）

陈阿三：（站在旁边，看得呆了）

（刘师傅炒完，把茶叶倒出来，放在竹匾上晾着）

刘师傅：闻闻。

陈阿三：（凑过去，闻了一下，有一股淡淡的茶香，没有糊味，没有生味，香得让人想流口水）

刘师傅：这就是炒茶。你刚才炒那锅，你自己闻闻。

陈阿三：（走到旁边的竹匾旁，闻了一下，一股糊味扑鼻而来）

刘师傅：这锅不能要了，倒掉。

陈阿三：（愣住）倒……倒掉？

刘师傅：不然呢？你想喝糊茶？

陈阿三：（脸烧得通红）

刘师傅：还愣着干什么？倒掉啊！

（陈阿三拿起竹匾，走到墙角的垃圾桶旁，把茶叶倒了进去。他看着那些糊了的茶叶，心里突然想到：他爹当年，是不是也这么倒过茶叶？）

刘师傅：回来。

陈阿三：（走回来，低着头，不敢看刘师傅）

刘师傅：你今天第一天，我不骂你。下班了，明天再来。

陈阿三：（点头，转身要走）

刘师傅：等等。（掏出一个塑料瓶，递过去）擦擦手，手上都是茶油。

陈阿三：（愣了一下，接过瓶子，看了一眼）洗洁精？

刘师傅：以后每天带一块肥皂来，炒完茶要洗手。（说完，转身走了）

**备注**：
- 展示刘师傅的严厉和阿三的笨拙
- 炒糊茶叶是喜剧场面
- 刘师傅的动作要专业、快速
- 刘师傅给洗洁精，刻画刀子嘴豆腐心
- 时长：1.5分钟
```

## 质量检查清单

创作剧本前，自检：

- [ ] 场景号连续？（S1-01、S1-02...）
- [ ] 人物表完整？
- [ ] 对白简洁？（不说长句）
- [ ] 对白口语化？（不说书面语）
- [ ] 对白符合90年代语境？（不说网络用语）
- [ ] 动作具体？（描述具体动作）
- [ ] 场景描述有画面感？（能想象出画面）
- [ ] 备注详细？（道具、音乐、特效）
- [ ] 总时长符合要求？（4-5分钟）

---

## 常见错误避免

❌ **不要这样做**:
- 对白太长（超过1分钟，不符合短剧节奏）
- 对白书面化（不说口语）
- 对白不符合90年代（说网络用语）
- 动作模糊（"阿三很紧张"→改为"阿三的手在发抖"）
- 场景描述冗长（超过30字）
- 备注太简单（没有具体要求）

✅ **应该这样做**:
- 对白简洁（15秒-1分钟）
- 对白口语化
- 对白符合90年代
- 动作具体（"阿三的手在发抖"）
- 场景描述简练（15-30字）
- 备注详细（道具、音乐、特效）

# Skill 15: 剧本审校

> **核心目标**: 审校剧本，确保符合短剧拍摄要求

---

## 触发时机

完成 Skill 14（剧本创作）后触发。

---

## 工作流程

### Step 1: 读取剧本

**读取文件**：
- `_scripts/drafts/第{集数}集-标题.md`

**提取信息**：
- 场景列表
- 对白内容
- 总时长

---

### Step 2: 第一遍审校 - 内容审校

**检查项**：

#### 1. 情节连贯
- [ ] 情节是否连贯？（前后无矛盾）
- [ ] 情节是否符合小说？
- [ ] 情节是否合理？

#### 2. 人物性格
- [ ] 人物性格是否一致？
- [ ] 刘师傅是否嘴毒？
- [ ] 阿三是否憨厚？
- [ ] 王胖子是否油滑？

#### 3. 对白风格
- [ ] 对白是否符合90年代语境？
- [ ] 对白是否口语化？
- [ ] 对白是否简短？
- [ ] 对白是否说网络用语？

#### 4. 逻辑矛盾
- [ ] 是否有时间矛盾？（S1-01是日，S1-02是夜）
- [ ] 是否有地点矛盾？（从茶厂门口直接到办公楼，合理）
- [ ] 是否有常识矛盾？

#### 5. 世界观一致
- [ ] 是否违反小说设定？
- [ ] 是否违反短剧设定？

**输出格式**:
```markdown
## 一、第一遍：内容审校

✅ 情节连贯，符合小说第1章
✅ 人物性格一致：
   - 刘师傅：嘴毒、严厉
   - 陈阿三：憨厚、反应慢
   - 王胖子：油滑、嘴甜
✅ 对白口语化，无现代网络用语
✅ 无逻辑矛盾
✅ 无世界观冲突
```

---

### Step 3: 第二遍审校 - 短剧适配审校

**检查项**：

#### 1. 开场3秒有冲突/悬念
- [ ] 前3秒是否有吸引人的画面或对白？
- [ ] 前3秒是否有冲突或悬念？

#### 2. 每1分钟有转折
- [ ] 第1分钟是否有转折？
- [ ] 第2分钟是否有转折？
- [ ] 第3分钟是否有转折？
- [ ] 第4分钟是否有转折？

#### 3. 对白密集，节奏快
- [ ] 对白是否密集？
- [ ] 对白是否简洁？
- [ ] 节奏是否快？

#### 4. 心理描写转化为动作/对白
- [ ] 是否有心理描写？
- [ ] 心理描写是否转化为动作或对白？
- [ ] 是否还有"阿三心里想..."这样的描述？

#### 5. 旁白使用合理（不超过20%）
- [ ] 旁白是否合理？
- [ ] 旁白是否不超过总时长的20%？
- [ ] 旁白是否用于补充信息，而非代替对白？

**输出格式**:
```markdown
## 二、第二遍：短剧适配

✅ 开场3秒有冲突/悬念
   - S1-01：阿三进茶厂，看环境（开场有画面吸引力）

✅ 每1分钟有转折
   - 第1分钟：阿三报到，分到严厉的刘师傅
   - 第2分钟：刘师傅问"会干什么？"，阿三说"会欠钱"（反转）
   - 第3分钟：阿三炒糊茶叶
   - 第4分钟：刘师傅给洗洁精（刀子嘴豆腐心）
   - 第5分钟：旁白，悬念（刘师傅和阿三父亲的关系）

✅ 对白密集，节奏快
   - 对白简洁（15秒-1分钟）
   - 节奏快，不拖沓

✅ 心理描写转化为动作/对白
   - 阿三紧张→"阿三的手在发抖"
   - 阿三内心挣扎→用旁白代替

✅ 旁白合理
   - 只在结尾使用旁白
   - 旁白时长约1.5分钟，占总时长的30%（超过20%，需要调整）
```

---

### Step 4: 第三遍审校 - 技术审校

**检查项**：

#### 1. 场景号连续
- [ ] 场景号是否连续？（S1-01、S1-02...）
- [ ] 场景号是否正确？

#### 2. 人物表完整
- [ ] 人物表是否完整？
- [ ] 每个人物是否有简介？

#### 3. 场景描述具体
- [ ] 场景描述是否具体？
- [ ] 场景描述是否有画面感？

#### 4. 镜头指示清晰
- [ ] 镜头指示是否清晰？
- [ ] 镜头转换是否合理？

#### 5. 备注详细
- [ ] 道具是否详细？
- [ ] 音乐是否详细？
- [ ] 特效是否详细？
- [ ] 备注是否有拍摄注意事项？

**输出格式**:
```markdown
## 三、第三遍：技术

✅ 场景号连续
   - S1-01、S1-02、S1-03、S1-04、S1-05

✅ 人物表完整
   - 陈阿三：18岁，茶厂学徒
   - 刘师傅：50多岁，制茶师傅
   - 王胖子：18岁，学徒
   - 眼镜叔：40多岁，厂里办事员

✅ 场景描述具体
   - 每个场景都有场景描述
   - 场景描述有画面感

✅ 镜头指示清晰
   - 每个场景都有镜头指示
   - 镜头转换合理

✅ 备注详细
   - 道具：铁铲、洗洁精、茶叶
   - 音乐：无特别音乐要求
   - 特效：炒茶的噼啪声
   - 备注有拍摄注意事项
```

---

### Step 5: 问题与修改

**列出问题并修改**：

**问题1**: 旁白超过20%
```markdown
❌ 问题1：S1-05 旁白时长约1.5分钟，占总时长的30%（超过20%）
   修改：
   - 缩短旁白，用动作和表情代替
   - 旁白从1.5分钟缩短到1分钟
   - 增加阿三的表情和动作（皱眉、叹气、转身）
```

**问题2**: S1-02 对白太长
```markdown
❌ 问题2：S1-02 对白时长30秒，但可以更简洁
   修改：
   - 删除冗余对白
   - 王胖子的自我介绍可以简化
   - 修改后时长：25秒
```

## 常见错误避免

❌ **不要这样做**:
- 跳过审校，直接认为剧本没问题
- 只检查技术，不检查内容
- 只检查内容，不检查短剧适配
- 审校报告太简单（没有具体问题）
- 审校报告没有修改建议

✅ **应该这样做**:
- 三遍审校全部执行（内容、短剧适配、技术）
- 每遍都有详细的检查项
- 审校报告详细（具体问题、修改建议）
- 最终版本明确（修改后的版本号）

# Skill 12: 人物改编

> **核心目标**: 将小说人物改编为剧本人物，适配短剧形式

---

## 触发时机

完成 Skill 11（短剧结构规划）后，用户确认结构规划后触发。

---

## 工作流程

### Step 1: 读取人物信息

**读取文件**：
- `_scripts/adaptations/小说分析报告.md`（人物图谱部分）
- `_briefs/小说名-设定brief.md`（主要人物设定部分）

**提取信息**：
- 每个人物的基本信息（姓名、身份、年龄）
- 性格特点（关键词）
- 核心目标（想要什么）
- 成长弧线（从开始到结束的变化）
- 与主角关系
- 在小说中的作用

**Think Aloud 示例**:
```
我需要先了解小说中的人物...

计划：
1. 读取《小说分析报告》中的人物图谱
2. 读取设定文档中的人物设定
3. 为每个人物提取：
   - 基本信息（姓名、身份、年龄）
   - 性格特点
   - 核心目标
   - 成长弧线
   - 与主角关系
   - 在小说中的作用
```

---

### Step 2: 制定人物改编策略

**决策**：
- **保留人物**：核心人物（主角、主要配角、反派）
- **合并人物**：次要人物合并（减少演员成本）
- **删除人物**：对主线无关的小角色

**输出格式**:
```markdown
## 二、人物改编策略

### 保留人物（必须保留）
| 人物 | 理由 |
|------|------|
| 陈阿三 | 主角，故事核心 |
| 刘师傅 | 核心配角，师父，推动情节 |
| 王胖子 | 配角，阿三的对照组 |
| 李小花 | 配角，阿三的恋人，提供支持 |
| 周经理 | 反派，提供外部冲突 |

### 合并人物（次要人物合并）
| 合并方式 | 结果 |
|----------|------|
| 其他学徒（张师傅的徒弟） | 合并为"群众学徒"，背景人物 |
| 其他工人 | 合并为"群众工人"，背景人物 |

### 删除人物（对主线无关）
| 人物 | 理由 |
|------|------|
| 赵厂长 | 作用可以合并到周经理 |
| 孙师傅 | 对比作用可以简化 |

**改编原则**：
- 保留核心人物（推动主线、塑造主角）
- 合并次要人物（减少演员成本，不增加演员人数）
- 删除无关人物（对主线无影响）
```

---

### Step 3: 改编核心人物

**为每个保留的人物设计剧本改编方案**：

#### 改编要点：
1. **性格外化**：小说心理描写 → 剧本台词/动作
2. **形象设计**：外貌、服装、道具建议
3. **演员要求**：年龄、体型、演技要求
4. **台词风格**：口语化、简洁、符合人物性格
5. **出场频率**：在第几集出场、出场多少场

#### 输出格式：
```markdown
## 三、核心人物剧本改编

### 1. 陈阿三（主角）

#### 小说定位
- 基本信息：茶厂学徒→接班人，18-30岁
- 性格特点：憨厚、执着、机灵、有正义感、喜欢开玩笑
- 核心目标：还债→学艺→传承技艺
- 成长弧线：从被动进厂→主动守护技艺
- 在小说中的作用：主角，故事核心

#### 剧本定位
- 基本信息：茶厂学徒→接班人，18-30岁
- 性格特点：憨厚、有正义感、关键时刻机灵
- 核心目标：还债→学艺→传承技艺
- 成长弧线：从被动进厂→主动守护技艺
- 在剧本中的作用：主角，推动主线

#### 改编要点
- **憨厚** → 表情木讷、反应慢半拍、不懂人情世故
- **执着** → 遇到困难坚持不放弃、被骂也不走
- **机灵** → 关键时刻一句话解决问题、化解尴尬
- **有正义感** → 看不惯投机取巧、坚持原则
- **喜欢开玩笑** → 用幽默化解压力、嘴巴贫

#### 视觉设计
**年龄分段**：
- 18岁（第1-6集）：青年演员（18-25岁）
- 30岁（第7-10集）：中年演员（26-35岁）

**外貌**：
- 18岁：略显单薄，青涩
- 30岁：结实稳重，成熟

**服装**：
- 工作服：朴素工装，蓝色或灰色
- 便装：90年代风格，简单朴素

**道具**：
- 铁铲：炒茶工具
- 茶具：喝茶工具

#### 演员要求
- 年龄：18-35岁（需要两个演员或通过化妆）
- 体型：适中，不要太胖或太瘦
- 演技要求：
  - 憨厚感（表情木讷、反应慢）
  - 机灵感（关键时刻眼神一亮）
  - 成长感（从青涩到成熟）

#### 台词风格
- 口语化：不说书面语
- 简洁：不说长句
- 90年代感：不说网络用语
- 偶尔说出"金句"："会欠钱"、"脑子是不是让门夹了？"

#### 出场频率
- 出场集数：全部10集
- 每集出场场数：3-5场
- 总出场场数：约40场

---

### 2. 刘师傅（核心配角）

#### 小说定位
- 基本信息：制茶师傅，50-60岁
- 性格特点：顽固、刀子嘴豆腐心、追求完美、重情义
- 核心目标：找接班人、守护技艺
- 成长弧线：从严厉→认可阿三
- 与主角关系：师父，像父子
- 在小说中的作用：核心配角，推动情节

#### 剧本定位
- 基本信息：制茶师傅，50-60岁
- 性格特点：严厉、嘴毒但关心徒弟
- 核心目标：找接班人、守护技艺
- 成长弧线：从严厉→认可阿三
- 与主角关系：师父，像父子
- 在剧本中的作用：核心配角，推动情节

#### 改编要点
- **顽固** → 拒绝现代化设备、坚持传统工艺
- **刀子嘴** → 骂人搞笑，不是真凶、语气凶但表情温和
- **豆腐心** → 偷偷给洗洁精、暗中关心
- **追求完美** → 对制茶工艺要求严格、一点差错都不能有
- **重情义** → 对茶厂有深厚感情、不愿看到技艺失传

#### 视觉设计
**年龄**：50-60岁

**外貌**：
- 严肃刻板，眉头常皱
- 手上有制茶的老茧
- 瘦高，精神矍铄

**服装**：
- 工作服：朴素工装，但整洁
- 便装：90年代老干部风格

**道具**：
- 茶具：喝茶工具
- 铁铲：炒茶工具（偶尔）

#### 演员要求
- 年龄：50-60岁
- 体型：瘦高，有精气神
- 演技要求：
  - 威严感（不怒自威）
  - 搞笑感（骂人要搞笑，不是真凶）
  - 温暖感（眼神要有关心）

#### 台词风格
- **嘴毒**："你这脑子是不是让门夹了？"、"笨得跟猪一样"
- 严肃，但带有幽默感
- 90年代语境，不说网络用语
- 偶尔流露出关心（语气缓和、眼神柔和）

#### 出场频率
- 出场集数：第1-9集（第10集退休）
- 每集出场场数：2-4场
- 总出场场数：约30场

### 3. 王胖子（配角）

#### 小说定位
- 基本信息：学徒，18-30岁
- 性格特点：油滑、偷懒、嘴巴甜
- 核心目标：赚钱、偷懒
- 成长弧线：从偷懒→意识到错误
- 与主角关系：师兄弟，阿三的对照组
- 在小说中的作用：配角，阿三的对照组

#### 剧本定位
- 基本信息：学徒，18-30岁
- 性格特点：偷懒、嘴巴甜
- 核心目标：赚钱、偷懒
- 成长弧线：从偷懒→意识到错误
- 与主角关系：师兄弟，阿三的对照组
- 在剧本中的作用：配角，阿三的对照组，提供喜剧

#### 改编要点
- **油滑** → 嘴甜会哄人、会拍马屁
- **偷懒** → 想方设法偷懒、被师父抓现行
- **嘴巴甜** → 会哄师父、但还是被骂

#### 视觉设计
**年龄分段**：
- 18岁（第1-6集）：青年演员（18-25岁）
- 30岁（第7-10集）：中年演员（26-35岁）

**外貌**：
- 胖胖的，圆滚滚的脸
- 眼睛眯成一条缝
- 笑起来像个弥勒佛

**服装**：
- 工作服：朴素工装，但比较松（因为胖）
- 便装：90年代风格，比较休闲

**道具**：
- 无特别道具

#### 演员要求
- 年龄：18-35岁
- 体型：微胖，圆脸
- 演技要求：
  - 喜剧感（搞笑、表情丰富）
  - 嘴甜感（会哄人、会拍马屁）

#### 台词风格
- 口语化、油滑
- 嘴甜："师父，您这手艺太好了！"
- 偷懒的理由很搞笑："我腰疼"、"我手酸"

#### 出场频率
- 出场集数：第1-7集（第8集后跳槽）
- 每集出场场数：1-3场
- 总出场场数：约15场

### 4. 李小花（配角）

#### 小说定位
- 基本信息：技术员，20-28岁
- 性格特点：聪明、坚持原则、有自己的想法
- 核心目标：支持阿三
- 成长弧线：从同事→恋人
- 与主角关系：同事→恋人
- 在小说中的作用：配角，帮助阿三成长，提供支持

#### 剧本定位
- 基本信息：技术员，20-28岁
- 性格特点：聪明、坚持原则、有自己的想法
- 核心目标：支持阿三
- 成长弧线：从同事→恋人
- 与主角关系：同事→恋人
- 在剧本中的作用：配角，帮助阿三成长，提供支持

#### 改编要点
- **聪明** → 反应快、学东西快
- **坚持原则** → 有自己的判断，不随波逐流
- **有自己的想法** → 对事情有独到见解

#### 视觉设计
**年龄分段**：
- 20岁（第1-6集）：青年演员（20-25岁）
- 28岁（第7-10集）：中年演员（26-30岁）

**外貌**：
- 清秀，有文化气质
- 眼神明亮，有主见

**服装**：
- 工作服：技术员服装，比较干净整洁
- 便装：90年代风格，知性大方

**道具**：
- 笔记本：记录技术参数
- 眼镜：可选，增加知性气质

#### 演员要求
- 年龄：20-30岁
- 体型：适中，清秀
- 演技要求：
  - 知性感（有文化气质）
  - 坚定感（有自己的判断）

#### 台词风格
- 理性、有逻辑
- 不油滑、不夸张
- 偶尔说出有深意的话

#### 出场频率
- 出场集数：第5-10集
- 每集出场场数：1-3场
- 总出场场数：约15场

### 5. 周经理（反派）

#### 小说定位
- 基本信息：茶厂经理，40-50岁
- 性格特点：务实、追求利润
- 核心目标：用现代化设备降低成本、提高利润
- 与主角冲突：传统技艺 vs 现代化
- 在小说中的作用：反派，提供外部冲突

#### 剧本定位
- 基本信息：茶厂经理，40-50岁
- 性格特点：务实、追求利润、有点急功近利
- 核心目标：用现代化设备降低成本、提高利润
- 与主角冲突：传统技艺 vs 现代化
- 在剧本中的作用：反派，提供外部冲突

#### 改编要点
- **务实** → 关注成本和利润
- **追求利润** → 想快速赚钱，不愿花时间陈化
- **有点急功近利** → 不愿意等，想快速看到结果

#### 视觉设计
**年龄**：40-50岁

**外貌**：
- 西装革履，比较正式
- 有商务气质

**服装**：
- 工作服：经理制服，比较正式
- 便装：西装，商务风格

**道具**：
- 文件：茶厂改制的文件
- 计算器：计算成本

#### 演员要求
- 年龄：40-50岁
- 体型：适中，有商务气质
- 演技要求：
  - 商务感（务实、理性）
  - 冲突感（和刘师傅、阿三的冲突）

#### 台词风格
- 商务风格、理性
- 关注成本："成本太高了"、"太慢了"
- 不情绪化，但坚定

#### 出场频率
- 出场集数：第5-6集
- 每集出场场数：2-3场
- 总出场场数：约10场
```

## 常见错误避免

❌ **不要这样做**:
- 保留太多人物（超过10个，增加成本）
- 改编要点空洞（只有"外化"，没有具体方法）
- 演员要求不具体（"好演技"太笼统）
- 台词风格不明确（不说口语化、不说90年代感）

✅ **应该这样做**:
- 保留核心人物（5个左右）
- 改编要点具体（表情、动作、台词都要明确）
- 演员要求具体（年龄、体型、演技要求）
- 台词风格明确（口语化、简洁、90年代感）

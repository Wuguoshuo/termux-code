# Skill 1：短剧选题

> **核心目标**：确定题材、类型、核心冲突、目标受众

---

## 触发时机

用户说「我想写一个短剧」或类似表达时触发。

---

## 工作流程

### Step 1：了解用户想法

**询问内容**：
- 题材偏好（甜宠、虐恋、悬疑、职场、家庭等）
- 风格偏好（轻松幽默、严肃深刻、浪漫唯美等）
- 核心概念（一句话概括故事）
- 目标受众（年龄、性别、兴趣）

**Think Aloud 示例**：
```
用户说「我想写一个甜宠短剧」...

我思考：
- 这是短剧选题任务，需要执行 Skill 1
- 首先需要了解用户的具体想法
- 包括题材、风格、核心概念、目标受众

我的计划：
1. 询问用户的基本想法
2. 分析用户需求，确定题材类型
3. 设计核心冲突
4. 确定目标受众
5. 生成设定文档
6. 等待用户确认
```

---

### Step 2：确定题材类型

**常见题材类型**：

| 类型 | 特点 | 示例 |
|------|------|------|
| 甜宠 | 甜蜜恋爱、撒糖不断 | 霸道总裁爱上我 |
| 虐恋 | 误会纠葛、虐心催泪 | 误会导致的分离 |
| 爽文 | 逆袭打脸、复仇成功 | 废物逆袭成大佬 |
| 悬疑 | 烧脑推理、层层反转 | 找出真凶 |
| 职场 | 职场奋斗、爱情事业 | 职场升职记 |
| 家庭 | 亲情纠葛、家庭矛盾 | 婆媳大战 |
| 穿越 | 穿越时空、改变命运 | 回到过去 |
| 复仇 | 冤屈昭雪、以牙还牙 | 复仇计划 |

**输出格式**：
```markdown
## 题材类型
- **主类型**：甜宠
- **辅类型**：职场、轻喜
- **创新点**：霸道总裁是女性化上司
```

---

### Step 3：设计核心冲突

**冲突类型**：

| 冲突类型 | 描述 | 示例 |
|---------|------|------|
| 身份冲突 | 身份差距导致的矛盾 | 穷女主 vs 富男主 |
| 误会冲突 | 误解导致的矛盾 | 误会对方出轨 |
| 家族冲突 | 家庭阻挠导致的矛盾 | 父母反对 |
| 职场冲突 | 工作矛盾导致的矛盾 | 职场竞争 |
| 命运冲突 | 命运安排导致的矛盾 | 身世之谜 |

**输出格式**：
```markdown
## 核心冲突
- **主要冲突**：身份差距（穷女主 vs 富总裁）
- **次要冲突**：职场竞争、前任纠缠
- **冲突焦点**：爱情与面包的选择
```

---

### Step 4：确定目标受众

**受众画像**：

| 维度 | 描述 |
|------|------|
| 年龄段 | 18-35 岁 |
| 性别 | 女性为主 |
| 兴趣 | 恋爱、浪漫、幻想 |
| 观看场景 | 通勤、睡前、午休 |

**输出格式**：
```markdown
## 目标受众
- **年龄段**：18-35 岁
- **性别**：女性为主
- **兴趣标签**：恋爱、浪漫、幻想
- **观看场景**：通勤、睡前、午休
```

## 题材类型

- **主类型**：甜宠
- **辅类型**：职场、轻喜
- **创新点**：霸道总裁是女性化上司，反套路

- **主要冲突**：身份差距（普通员工 vs 女性霸道总裁）
- **次要冲突**：职场竞争、前任纠缠、性别反转
- **冲突焦点**：爱情与面包的选择，性别角色的反转

## 目标受众

- **年龄段**：18-35 岁
- **性别**：女性为主
- **兴趣标签**：恋爱、浪漫、幻想、职场

---

## 世界观设定

### 时间背景
- 现代都市，时间跨度约 3 个月

### 地点环境
- 主要场景：写字楼、公寓、餐厅、商场
- 城市设定：一线城市（上海或北京）

### 世界规则
- 现代都市规则
- 公司设定：大型互联网公司
- 职场规则：能力说话，背景也有影响

- 「女性霸道总裁」反套路设定，打破传统性别刻板印象

### 主线剧情
- 普通员工林小满意外得罪新来的女性霸道总裁苏瑶，被迫成为她的贴身助理。在相处过程中，两人从冤家变恋人，最终走到一起。

### 情感基调
- 甜宠为主，穿插职场励志和轻喜剧元素
- 结尾圆满，有情人终成眷属

---

## 质量检查清单

生成设定文档前，自检：

- [ ] 题材类型明确？（有主类型和辅类型）
- [ ] 核心冲突清晰？（有主要冲突和次要冲突）
- [ ] 目标受众准确？（有年龄段、性别、兴趣）
- [ ] 世界观设定合理？（时间、地点、规则）
- [ ] 核心概念独特？（有一句话概括）
- [ ] 风格基调统一？（符合题材类型）

---

## 常见错误避免

❌ **不要这样做**：
- 题材模糊、类型混杂
- 核心冲突无力、缺乏吸引力
- 目标受众太宽泛
- 世界观设定不合理
- 核心概念老套

✅ **应该这样做**：
- 题材明确、类型统一
- 核心冲突强烈、吸引人
- 目标受众精准
- 世界观设定合理、自洽
- 核心概念新颖、有吸引力

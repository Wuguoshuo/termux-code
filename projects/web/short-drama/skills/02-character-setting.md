# Skill 2：角色设定

> **核心目标**：创建主角、反派、配角的人物小传

---

## 触发时机

用户确认选题（Skill 1）后，或用户说「设定角色」「设计角色」时触发。

---

## 工作流程

### Step 1：读取设定文档

**读取文件**：
- `_briefs/[短剧名]-设定brief.md`

**提取信息**：
- 题材类型
- 核心冲突
- 目标受众
- 世界观设定

**Think Aloud 示例**：
```
用户确认了选题，现在需要设定角色...

我思考：
- 需要先读取设定文档
- 了解题材、冲突、受众、世界观
- 然后创建人物小传

我的计划：
1. 读取设定文档
2. 分析人物需求（主角、配角、反派）
3. 创建人物小传
4. 生成人物关系图
5. 等待用户确认
```

---

### Step 2：创建主角小传

**主角要素**：

| 要素 | 描述 | 示例 |
|------|------|------|
| 基本信息 | 姓名、年龄、身份 | 林小满，25 岁，普通员工 |
| 外貌特征 | 长相、身材、穿着 | 清纯可爱，穿着朴素 |
| 性格特点 | 核心性格、行为特征 | 善良、独立、有原则 |
| 核心目标 | 想要什么 | 升职加薪，获得认可 |
| 核心障碍 | 阻碍是什么 | 出身卑微，没有背景 |
| 成长弧线 | 从什么到什么 | 从自卑→自信，从普通→优秀 |
| 口头禅 | 标志性语言 | 「我可以的」 |

**输出格式**：
```markdown
### 主角

| 要素 | 内容 |
|------|------|
| 姓名 | 林小满 |
| 年龄 | 25 岁 |
| 身份 | 普通员工 |
| 外貌 | 清纯可爱，穿着朴素 |
| 性格 | 善良、独立、有原则 |
| 目标 | 升职加薪，获得认可 |
| 障碍 | 出身卑微，没有背景 |
| 成长 | 从自卑→自信，从普通→优秀 |
| 口头禅 | 「我可以的」 |
```

### Step 3：创建反派小传

**反派要素**：

| 要素 | 描述 | 示例 |
|------|------|------|
| 基本信息 | 姓名、年龄、身份 | 苏瑶，30 岁，霸道总裁 |
| 外貌特征 | 气场、穿着 | 御姐范儿，穿着干练 |
| 性格特点 | 核心性格、行为特征 | 强势、果断、有原则 |
| 核心动机 | 想要什么 | 证明女性也能成为优秀领导者 |
| 与主角关系 | 初始关系→最终关系 | 冤家→恋人 |
| 洗白点 | 最终展现的脆弱面 | 童年缺爱，渴望真爱 |

**输出格式**：
```markdown
### 反派（实为官配）

| 要素 | 内容 |
|------|------|
| 姓名 | 苏瑶 |
| 年龄 | 30 岁 |
| 身份 | 霸道总裁 |
| 外貌 | 御姐范儿，穿着干练 |
| 性格 | 强势、果断、有原则 |
| 动机 | 证明女性也能成为优秀领导者 |
| 与主角关系 | 冤家→恋人 |
| 洗白点 | 童年缺爱，渴望真爱 |
```

### Step 4：创建配角小传

**配角类型**：

| 配角类型 | 作用 | 示例 |
|---------|------|------|
| 闺蜜/兄弟 | 提供建议，推动情节 | 闺蜜小美 |
| 情敌/对手 | 制造误会，增加冲突 | 前男友 |
| 神助攻 | 帮助主角，推进感情 | 同事老王 |
| 长辈 | 施加压力，增加困难 | 父母 |

**输出格式**：
```markdown
### 配角

| 角色 | 类型 | 作用 | 与主角关系 |
|------|------|------|-----------|
| 小美 | 闺蜜 | 提供建议，推动情节 | 闺蜜，支持者 |
| 王浩 | 情敌 | 制造误会，增加冲突 | 情敌，竞争者 |
| 老张 | 神助攻 | 帮助主角，推进感情 | 同事，支持者 |
| 林父 | 长辈 | 施加压力，增加困难 | 父亲，施加压力 |

#### 小美（闺蜜）

| 要素 | 内容 |
|------|------|
| 姓名 | 李小美 |
| 年龄 | 24 岁 |
| 身份 | 女主闺蜜 |
| 性格 | 活泼开朗，足智多谋 |
| 作用 | 为女主出谋划策，充当感情顾问 |
| 口头禅 | 「听我的，准没错」 |
```

### Step 5：创建人物关系图

**关系类型**：

| 关系类型 | 描述 | 示例 |
|---------|------|------|
| 主线关系 | 主角与官配 | 林小满 ←→ 苏瑶 |
| 对立关系 | 主角与反派 | 林小满 ←→ 王浩 |
| 支持关系 | 主角与闺蜜 | 林小满 ←→ 小美 |
| 家庭关系 | 主角与父母 | 林小满 ←→ 林父 |

## 质量检查清单

生成角色设定文档前，自检：

- [ ] 主角有明确的目标和障碍？
- [ ] 主角有成长弧线？
- [ ] 反派有合理的动机？
- [ ] 反派有洗白点？
- [ ] 配角有存在的意义？
- [ ] 人物关系清晰？
- [ ] 角色对比表完整？

---

## 常见错误避免

❌ **不要这样做**：
- 主角无趣、缺乏魅力
- 反派单薄、动机不合理
- 配角多余、作用不明确
- 人物关系混乱
- 角色对比表缺失

✅ **应该这样做**：
- 主角有魅力、有成长空间
- 反派有深度、有洗白点
- 配角有作用、性格鲜明
- 人物关系清晰、有逻辑
- 角色对比表完整、对比明显

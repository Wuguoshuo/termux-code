# Skill 7：剧本审校

> **核心目标**：审校剧本，确保符合短剧拍摄要求

---

## 触发时机

完成 Skill 6（剧本创作）后触发。

---

## 工作流程

### Step 1：读取剧本

**读取文件**：
- `drafts/第[集数]集-标题.md`

**提取信息**：
- 场景列表
- 对白内容
- 总时长

---

### Step 2：第一遍审校 - 内容审校

**检查项**：

#### 1. 情节连贯
- [ ] 情节是否连贯？（前后无矛盾）
- [ ] 情节是否符合分集大纲？
- [ ] 情节是否合理？

#### 2. 人物性格
- [ ] 人物性格是否一致？
- [ ] 对白是否符合人物性格？
- [ ] 动作是否符合人物性格？

#### 3. 对白风格
- [ ] 对白是否口语化？
- [ ] 对白是否简洁？
- [ ] 对白是否说网络用语？

#### 4. 逻辑矛盾
- [ ] 是否有时间矛盾？
- [ ] 是否有地点矛盾？
- [ ] 是否有常识矛盾？

**输出格式**：
```markdown
## 一、第一遍：内容审校

✅ 情节连贯，符合分集大纲
✅ 人物性格一致：
   - 苏瑶：强势、果断
   - 林小满：善良、焦急
✅ 对白口语化，无现代网络用语
✅ 无逻辑矛盾
```

---

### Step 3：第二遍审校 - 短剧适配审校

**检查项**：

#### 1. 开场 3 秒有冲突/悬念
- [ ] 前 3 秒是否有吸引人的画面或对白？
- [ ] 前 3 秒是否有冲突或悬念？

#### 2. 每 1 分钟有转折
- [ ] 第 1 分钟是否有转折？
- [ ] 第 2 分钟是否有转折？
- [ ] 第 3 分钟是否有转折？

#### 3. 对白密集，节奏快
- [ ] 对白是否密集？
- [ ] 对白是否简洁？
- [ ] 节奏是否快？

#### 4. 心理描写转化为动作/对白
- [ ] 是否有心理描写？
- [ ] 心理描写是否转化为动作或对白？
- [ ] 是否还有「阿三心里想...」这样的描述？

#### 5. 旁白使用合理（不超过 20%）
- [ ] 旁白是否合理？
- [ ] 旁白是否不超过总时长的 20%？

**输出格式**：
```markdown
## 二、第二遍：短剧适配

✅ 开场 3 秒有冲突/悬念
   - S1-01：林小满上班迟到（开场有画面吸引力）

✅ 每 1 分钟有转折
   - 第 1 分钟：林小满撞到苏瑶（意外）
   - 第 2 分钟：得知新上司很凶（担忧）
   - 第 3 分钟：被任命为助理（转折）

✅ 对白密集，节奏快
   - 对白简洁（15 秒-1 分钟）
   - 节奏快，不拖沓

✅ 心理描写转化为动作/对白
   - 林小满内心独白「完了完了」

✅ 旁白合理
   - 只在最后场景使用内心独白
   - 旁白时长约 10 秒，占总时长的 3%（合理）
```

---

### Step 4：第三遍审校 - 技术审校

**检查项**：

#### 1. 场景号连续
- [ ] 场景号是否连续？（S1-01、S1-02...）
- [ ] 场景号是否正确？

#### 2. 人物表完整
- [ ] 人物表是否完整？
- [ ] 每个人物是否有简介？

#### 3. 场景描述具体
- [ ] 场景描述是否具体？
- [ ] 场景描述是否有画面感？

#### 4. 镜头指示清晰
- [ ] 镜头指示是否清晰？
- [ ] 镜头转换是否合理？

#### 5. 备注详细
- [ ] 道具是否详细？
- [ ] 音乐是否详细？
- [ ] 特效是否详细？
- [ ] 备注是否有拍摄注意事项？

**输出格式**：
```markdown
## 三、第三遍：技术

✅ 场景号连续
   - S1-01、S1-02、S1-03、S1-04、S1-05

✅ 人物表完整
   - 林小满：普通员工，25 岁
   - 苏瑶：霸道总裁，30 岁
   - 李小美：闺蜜，24 岁

✅ 场景描述具体
   - 每个场景都有场景描述
   - 场景描述有画面感

✅ 镜头指示清晰
   - 每个场景都有镜头指示
   - 镜头转换合理

✅ 备注详细
   - 道具：有（文件、手表等）
   - 音乐：无特别音乐要求
   - 特效：无
   - 备注有拍摄注意事项
```

---

### Step 5：问题与修改

**列出问题并修改**：

**问题示例**：
```markdown
❌ 问题 1：S1-03 对白可以更简洁
   修改：
   - 删除冗余对白
   - 修改后时长：25 秒
```

---

### Step 6：生成审校报告

**保存位置**：
- `_logs/第[集数]集-剧本审校报告.md`

**文件结构**：
```markdown
# 第 [集数] 集：[标题] - 剧本审校报告

## 一、第一遍：内容审校
（Step 2 输出）

## 二、第二遍：短剧适配
（Step 3 输出）

## 三、第三遍：技术
（Step 4 输出）

## 四、问题与修改
（Step 5 输出）

## 五、最终版本
- 修改后的剧本版本：`drafts/第[集数]集-标题-v2.md`
- 可提交拍摄

---

**审校时间**：[时间]
**审校人**：CodeBuddy
```

## 质量检查清单

生成审校报告前，自检：

- [ ] 第一遍：内容审校完成？
- [ ] 第二遍：短剧适配审校完成？
- [ ] 第三遍：技术审校完成？
- [ ] 问题与修改详细？
- [ ] 最终版本明确？

---

## 常见错误避免

❌ **不要这样做**：
- 跳过审校，直接认为剧本没问题
- 只检查技术，不检查内容
- 只检查内容，不检查短剧适配
- 审校报告太简单（没有具体问题）
- 审校报告没有修改建议

✅ **应该这样做**：
- 三遍审校全部执行（内容、短剧适配、技术）
- 每遍都有详细的检查项
- 审校报告详细（具体问题、修改建议）
- 最终版本明确（修改后的版本号）

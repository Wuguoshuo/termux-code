# Skill 4：分集大纲

> **核心目标**：规划每集的时长、场景数、核心事件

---

## 触发时机

用户确认故事大纲（Skill 3）后，或用户说「分集」「每集内容」时触发。

---

## 工作流程

### Step 1：读取故事大纲

**读取文件**：
- `drafts/[短剧名]-故事大纲.md`

**提取信息**：
- 起承转合结构
- 关键转折点
- 情感曲线
- 伏笔与呼应

**Think Aloud 示例**：
```
用户确认了故事大纲，现在需要分集...

我思考：
- 需要先读取故事大纲
- 了解起承转合、关键转折点、情感曲线
- 然后规划每集的内容

我的计划：
1. 读取故事大纲
2. 规划每集的核心事件
3. 分配集数
4. 设计每集的关键情节点
5. 生成分集大纲文档
6. 等待用户确认
```

---

### Step 2：规划分集结构

**分集原则**：

| 阶段 | 集数范围 | 核心内容 | 每集重点 |
|------|---------|---------|---------|
| 起 | 第 1-10 集 | 人物出场、关系建立 | 冲突建立、人物立住 |
| 承 | 第 11-50 集 | 感情发展、甜蜜升温 | 撒糖、暧昧、甜蜜 |
| 转 | 第 51-70 集 | 误会产生、关系破裂 | 虐心、冲突、高潮 |
| 合 | 第 71-80 集 | 和好如初、完美收尾 | 甜蜜、圆满、升华 |

**输出格式**：
```markdown
## 分集概览

| 阶段 | 集数 | 核心内容 | 集数占比 |
|------|------|---------|---------|
| 起 | 第 1-10 集 | 人物出场、关系建立 | 12.5% |
| 承 | 第 11-50 集 | 感情发展、甜蜜升温 | 50% |
| 转 | 第 51-70 集 | 误会产生、关系破裂 | 25% |
| 合 | 第 71-80 集 | 和好如初、完美收尾 | 12.5% |
```

### Step 3：设计每集核心事件

**每集要素**：

| 要素 | 描述 | 示例 |
|------|------|------|
| 集数 | 第几集 | 第 1 集 |
| 标题 | 本集标题 | 「命运的相遇」 |
| 时长 | 本集时长 | 4-5 分钟 |
| 场景数 | 本集场景数 | 5-8 场 |
| 核心事件 | 本集最重要的事件 | 林小满在电梯里撞到苏瑶 |
| 关键对白 | 本集最关键的台词 | 「你叫什么名字？」 |
| 情感线 | 本集情感变化 | 冲突 → 好奇 |
| 伏笔/呼应 | 本集埋下的伏笔或呼应的前面内容 | 埋下苏瑶「受过伤」的伏笔 |

## 常见错误避免

❌ **不要这样做**：
- 分集结构不合理（起太长、转太突然）
- 每集内容空洞、无重点
- 关键情节点模糊
- 金句/名场面缺失
- 伏笔遗漏、呼应混乱
- 与故事大纲矛盾

✅ **应该这样做**：
- 分集结构合理、节奏感强
- 每集内容充实、有吸引力
- 关键情节点清晰、有冲击力
- 金句/名场面精心设计
- 伏笔巧妙、呼应自然
- 与故事大纲保持一致

# Skill 3：故事大纲

> **核心目标**：设计主线剧情、起承转合、关键转折点

---

## 触发时机

用户确认角色设定（Skill 2）后，或用户说「故事大纲」「设计剧情」时触发。

---

## 工作流程

### Step 1：读取设定文档和角色设定

**读取文件**：
- `_briefs/[短剧名]-设定brief.md`
- `_briefs/[短剧名]-角色设定.md`

**提取信息**：
- 题材类型
- 核心冲突
- 世界观设定
- 人物关系

**Think Aloud 示例**：
```
用户确认了角色设定，现在需要设计故事大纲...

我思考：
- 需要先读取设定文档和角色设定
- 了解题材、冲突、世界观、人物关系
- 然后设计主线剧情和起承转合

我的计划：
1. 读取设定文档和角色设定
2. 设计主线剧情
3. 设计起承转合
4. 设计关键转折点
5. 生成故事大纲文档
6. 等待用户确认
```

---

### Step 2：设计主线剧情

**主线剧情结构**：

| 阶段 | 描述 | 示例 |
|------|------|------|
| 初始状态 | 主角的日常生活 | 林小满是普通员工，每天两点一线 |
| 激励事件 | 打破平衡的事件 | 新霸道总裁上任，林小满得罪了她 |
| 上升动作 | 冲突升级的过程 | 林小满成为苏瑶的贴身助理 |
| 高潮 | 最大冲突的时刻 | 林小满发现苏瑶的秘密，两人关系破裂 |
| 结局 | 故事最终状态 | 两人和好如初，在一起 |

**输出格式**：
```markdown
## 主线剧情

### 初始状态
- **时间**：故事开始前
- **状态**：主角的日常生活
- **背景**：主角的身份、处境

### 激励事件
- **事件**：打破平衡的事件
- **反 转**：事件的反转点

### 上升动作
- **阶段 1**：冲突升级的开始
- **阶段 2**：冲突的持续升级
- **阶段 3**：冲突达到顶峰

### 高潮
- **事件**：最大冲突的时刻
- **冲突**：核心矛盾的爆发
- **选择**：主角的选择

### 结局
- **状态**：故事的最终状态
- **主题**：主题的升华
- **基调**：结局的基调
```

### Step 3：设计起承转合

**起承转合结构**：

| 阶段 | 描述 | 集数 | 内容 |
|------|------|------|------|
| 起 | 故事开始，人物出场 | 第 1-10 集 | 冤家路窄，互相看不顺眼 |
| 承 | 冲突发展，情感升温 | 第 11-50 集 | 暧昧升温，产生好感 |
| 转 | 重大转折，关系破裂 | 第 51-70 集 | 误会产生，关系破裂 |
| 合 | 结局收尾，有情人终成眷属 | 第 71-80 集 | 和好如初，在一起 |

**输出格式**：
```markdown
## 起承转合

### 起（第 1-10 集）
- **核心**：冤家路窄，互相看不顺眼
- **目标**：建立人物关系，埋下伏笔
- **关键情节点**：
  - 林小满得罪新上司苏瑶
  - 被迫成为苏瑶的贴身助理
  - 两人互相看不顺眼

### 承（第 11-50 集）
- **核心**：暧昧升温，产生好感
- **目标**：发展感情，制造甜蜜
- **关键情节点**：
  - 林小满的工作能力得到认可
  - 苏瑶对林小满产生好感
  - 两人关系逐渐改善

### 转（第 51-70 集）
- **核心**：误会产生，关系破裂
- **目标**：制造冲突，推动高潮
- **关键情节点**：
  - 林小满发现苏瑶的秘密
  - 误会产生，两人关系破裂
  - 林小满离开公司

### 合（第 71-80 集）
- **核心**：和好如初，在一起
- **目标**：解决冲突，完美收尾
- **关键情节点**：
  - 苏瑶挽回林小满
  - 两人解除误会
  - 有情人终成眷属
```

## 质量检查清单

生成故事大纲文档前，自检：

- [ ] 主线剧情完整？（起始、激励、上升、高潮、结局）
- [ ] 起承转合合理？（起承转合各阶段内容明确）
- [ ] 关键转折点有力？（转折点清晰、有影响力）
- [ ] 情感曲线合理？（甜蜜与虐心分配均衡）
- [ ] 伏笔与呼应到位？（有伏笔、有呼应）
- [ ] 与角色设定一致？（人物行为符合性格）

---

## 常见错误避免

❌ **不要这样做**：
- 主线剧情拖沓、无聊
- 起承转合不合理（起太长、转太突然）
- 关键转折点无力、平淡
- 情感曲线失衡（太甜或太虐）
- 伏笔遗漏、呼应缺失
- 与角色设定矛盾

✅ **应该这样做**：
- 主线剧情紧凑、有吸引力
- 起承转合合理、节奏感强
- 关键转折点有力、震撼人心
- 情感曲线均衡、有起伏
- 伏笔巧妙、呼应自然
- 与角色设定一致

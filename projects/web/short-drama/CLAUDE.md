# 原创短剧创作系统

> 版本：1.0
> 最后更新：2025-12-31

这是一个用于原创短剧创作的系统，包含完整的创作流程和 7 个 Skills。

---

## 任务类型定义

本系统支持以下任务类型：

| 类型标识 | 任务类型 | 描述 | 触发条件 |
|---------|---------|------|---------|
| **A** | 短剧选题 | 确定题材、类型、核心冲突、目标受众 | 用户说"我想写一个短剧" |
| **B** | 角色设定 | 创建主角、反派、配角的人物小传 | 用户确认选题后 |
| **C** | 故事大纲 | 设计主线剧情、起承转合、关键转折点 | 用户确认角色设定后 |
| **D** | 分集大纲 | 规划每集的时长、场景数、核心事件 | 用户确认故事大纲后 |
| **E** | 场景大纲 | 为每集设计详细场景，包含情绪曲线 | 用户确认分集大纲后 |
| **F** | 剧本创作 | 撰写完整剧本，包含台词、动作、镜头指示 | 用户确认场景大纲后 |
| **G** | 剧本审校 | 检查格式、逻辑、拍摄可行性 | 用户创作完剧本后 |

## 创作规范

### 短剧格式要求

| 项目 | 要求 |
|------|------|
| 单集时长 | 4-5 分钟 |
| 场景数 | 5-8 场 |
| 对白 | 每句不超过 30 字 |
| 总集数 | 10-80 集（竖屏短剧） |
| 开场 | 3 秒内有冲突或悬念 |
| 节奏 | 每 1 分钟有转折 |

### 场景编号规则

```
S[集数]-[场景序号] [场景名] - [时间段]

示例：
S1-01 公司门口 - 日
S1-02 总裁办公室 - 日
S2-01 女主家 - 夜
```

### 时间段标识

| 标识 | 含义 |
|------|------|
| 日 | 白天（日出后、日落前） |
| 夜 | 夜晚（日落后、日出前） |
| 晨 | 清晨（日出前后） |
| 黄昏 | 傍晚（日落前后） |
| 内 | 室内 |
| 外 | 室外 |

## 常见错误避免

### 选题阶段
❌ 不要：题材模糊、类型混杂、冲突无力
✅ 应该：题材明确、类型统一、冲突强烈

### 角色阶段
❌ 不要：主角无趣、反派单薄、配角多余
✅ 应该：主角有魅力、反派有深度、配角有作用

### 故事阶段
❌ 不要：情节拖沓、转折突兀、结局草率
✅ 应该：节奏紧凑、转折自然、结局圆满

### 分集阶段
❌ 不要：集与集脱节、每集无重点、伏笔遗漏
✅ 应该：集与集连贯、每集有重点、伏笔回收

### 场景阶段
❌ 不要：场景冗余、描述空洞、情绪平淡
✅ 应该：场景精炼、描述生动、情绪起伏

### 剧本阶段
❌ 不要：对白冗长、动作模糊、备注缺失
✅ 应该：对白精炼、动作清晰、备注完整

### 审校阶段
❌ 不要：跳过审校、审校不彻底、问题不修复
✅ 应该：三遍审校、每遍彻底、问题全修复

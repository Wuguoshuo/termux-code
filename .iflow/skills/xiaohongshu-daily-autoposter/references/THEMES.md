## 主题详细配置

### 1. Vibrant Pop（活力流行）

**适用领域**:
- 美妆护肤
- 时尚穿搭
- 生活方式
- 娱乐休闲

**配色方案**:
```
主色: #FF6B6B (珊瑚红)
辅助色1: #4ECDC4 (青色)
辅助色2: #FFE66D (黄色)
辅助色3: #95E1D3 (薄荷绿)
点缀色: #F38181 (鲑鱼粉)

背景色: #FFFFFF (纯白)
强调色: #FF6B6B (珊瑚红)
```

**字体搭配**:
```

正文: NotoSansSC-Regular
```

**布局推荐**:
- 居中布局：突出标题和核心信息
- 分割布局：左右对比，视觉冲击
- 卡片布局：层次分明，重点突出

**适用emoji**:
```
✨ 💫 🌟 ⭐ 🔥 💥 ⚡ 🚀 💪 👑
```

## 布局变体说明

### 1. Centered（居中布局）

**特点**: 标题居中，背景有装饰性几何图形

**适用场景**:
- 简洁明了的单点信息
- 需要快速传达核心内容
- 配合鲜艳配色使用效果佳

**设计要点**:
- 中心大标题，突出醒目
- 背景使用圆形/放射形装饰
- 保持视觉平衡

---

### 2. Bottom-Heavy（底部强调）

**特点**: 标题放置在底部面板，背景渐变

**适用场景**:
- 需要留白上部展示品牌元素
- 标题较长，需要更多横向空间
- 希望营造高端大气感

**设计要点**:
- 底部1/3区域作为标题面板
- 背景使用垂直渐变
- 顶部可添加装饰元素

---

### 3. Split（分割布局）

**特点**: 对角线或垂直分割，两种颜色区域

**适用场景**:
- 对比类内容
- 强调变化/差异
- 希望增加视觉动感

**设计要点**:
- 两种颜色的对角线分割
- 标题放在较浅颜色区域
- 可添加标签元素

---

### 4. Card（卡片布局）

**特点**: 中心有圆角卡片，背景有点缀图案

**适用场景**:
- 需要突出内容容器感
- 希望增加层次感
- 配合暖色调使用

**设计要点**:
- 中心大圆角卡片
- 背景有细节点缀
- 卡片有边框装饰

---

### 5. Gradient（渐变布局）

**特点**: 径向渐变背景，标题带阴影

**适用场景**:
- 需要强烈的视觉冲击
- 配合冷色调使用
- 希望营造梦幻/科技感

**设计要点**:
- 中心到边缘的径向渐变
- 标题带投影效果
- 可添加光泽效果

## 平台规范

### 图片尺寸
```
推荐尺寸: 1000 x 1500 像素 (3:4 比例)
最小尺寸: 600 x 800 像素
文件格式: PNG 或 JPG
文件大小: < 10MB
```

### 文字规范
```
标题文字: 48-72px
副标题文字: 32-48px
正文文字: 24-36px
标签文字: 18-24px
```

### 视觉原则
```
1. 保持简洁，不要过于复杂
2. 确保文字清晰可读
3. 色彩搭配要协调
4. 留白要适度
5. 保持品牌一致性
```

## 使用建议

1. **根据内容选择主题**:
   - 美妆/时尚 → Vibrant Pop
   - 职场/学习 → Modern Minimalist
   - 美食/旅行 → Warm Vintage
   - 数码/科技 → Tech Blue
   - 健身/养生 → Nature Green

2. **根据场景选择布局**:
   - 快速传达 → Centered
   - 强调变化 → Split
   - 突出层次 → Card
   - 营造氛围 → Gradient

3. **色彩搭配技巧**:
   - 主色 + 辅助色 + 点缀色
   - 保持色彩数量在3-5种
   - 确保足够的对比度
